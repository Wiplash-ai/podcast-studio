# Security policy

Podcast Studio handles private audio, video, identity, and room capabilities.

Report suspected vulnerabilities privately through GitHub's security advisory
feature for this repository. Do not include credentials, private room links,
customer media, or personal information in a public issue.

The project treats cross-session media access, unprovable recording consent,
secret leakage, client-side authorization decisions, and exposed private-service
implementation as critical security defects.
